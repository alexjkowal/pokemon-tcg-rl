# Pokemon TCG Reinforcement Learning

A model-free reinforcement learning project for the Pokemon Trading Card Game.

The project will include:

- A deterministic Pokemon TCG game engine
- Legal-action generation and action masking
- Random and heuristic baseline agents
- Gymnasium and PettingZoo environments
- GPU-accelerated reinforcement learning
- Self-play training and agent evaluation

## Environment

Create the Conda environment with:

```bat
conda env create -f environment-windows-gpu.yml
conda activate pokemon-tcg-rl
```
